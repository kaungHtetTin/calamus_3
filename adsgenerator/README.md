# Calamus Education language-learning campaign

Three-slide promotional campaign for Calamus Education, designed as a `1000 × 1600` portrait carousel for Myanmar mobile audiences.

## Campaign strategy

1. **Awareness:** present five verified language paths: English, Korean, Chinese, Japanese, and Russian.
2. **Value:** introduce verified learning tools: online courses, vocabulary practice, speaking dialogues, and the mini library.
3. **Action:** direct viewers to the three Android apps currently listed in the project data.

The campaign intentionally makes no free-price, popularity, guaranteed-result, or unverified performance claims.

## Preview

Open `index.html` directly in a browser. Use the buttons or left/right arrow keys to navigate. Press `O` or select **Overview** to review the entire campaign.

## Capture URLs

- `index.html?slide=1&capture=1`
- `index.html?slide=2&capture=1`
- `index.html?slide=3&capture=1`

Capture mode hides controls and page padding. Every slide is exactly `1000 × 1600` pixels.

## Files

- `index.html` — semantic campaign content
- `styles.css` — complete offline visual design
- `script.js` — navigation, overview, query-string selection, and capture mode
- `exports/` — ready-to-post PNG exports for this campaign

No external fonts, CDNs, libraries, APIs, or application dependencies are used.
